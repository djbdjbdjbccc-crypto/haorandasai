怎么往这里加项目

这个页面读的是仓库里的 projects.json，加项目 = 往这个文件里加一条，再 push 上去，约 1 分钟自动更新：

  1. 手动：编辑 projects.json，照下面的格式加一条，git add . && git commit -m "add project" && git push
  2. 用 agy：在仓库文件夹里跟它说“把 XX 项目加到 projects.json，描述是……”
  3. 或者直接告诉天天，报项目名和一句话描述就行
{
  "name": "项目名",
  "desc": "一句话到三句话的说明",
  "tags": ["标签1", "标签2"],
  "date": "2026-11",
  "status": "进行中",
  "link": "https://……（可选）"
}

项目文件本身也可以直接放进仓库的文件夹里，再在 link 里写相对路径指过去。
