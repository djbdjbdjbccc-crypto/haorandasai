怎么往这里加项目 & 提示词

页面直接读取仓库根目录的 projects.json。新增项目时往数组里加一条记录并 push，约 1 分钟自动生效：

  1. 独立网页项目：把单文件 HTML 放进 projects/ 目录，在 link 中写相对路径（如 projects/villa-jelly.html），卡片会自动出现“打开网页”按钮。
  2. 附带提示词：在条目里补充 prompt 字段，卡片会自动生成“查看提示词”弹窗与一键复制功能。
  3. 提交更新：git add . && git commit -m "add project" && git push，或直接让 AI 帮你更新。
